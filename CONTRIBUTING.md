# Contributing to WinCare-Pro

Thank you for considering contributing!

## How to Contribute

- Fork the repository and create your branch from `main`.
- Write clear, modular code and follow PowerShell best practices.
- Add or update comment-based help for all functions.
- Add or update tests in the `tests/` folder using Pester.
- Ensure your code passes all tests before submitting a pull request.
- Describe your changes clearly in the pull request.

## Code of Conduct

Be respectful and constructive. See the [Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
