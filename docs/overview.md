# WinCare-Pro Documentation

Welcome to the documentation for WinCare-Pro. This module provides essential tools for Windows system health, service monitoring, and cleanup.

## Functions

- **Get-SystemHealth**: Returns disk and memory health.
- **Test-ServiceStatus**: Lists stopped auto-start services.
- **Invoke-QuickCleanup**: Cleans temp files (supports -WhatIf).

See the main README for installation and usage examples.
